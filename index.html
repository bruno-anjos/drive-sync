Drive Sync

Drive Sync is a private tool, not a public service. It connects one person's own server to a single folder in that same person's Google Drive, using rclone, so documents processed on the server are filed in Drive.

It asks Google only for access to the files and folders it creates itself (the drive.file scope). It can't see anything else in the Drive.

It isn't offered to anyone else, and there is no sign-up.
